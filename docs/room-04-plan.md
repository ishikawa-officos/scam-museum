# 第4展示室（企画メモ・ドラフト）
## 仮題「みんな、儲かっている」— LINEグループ型 投資詐欺（サクラ劇団型）

- 作成日: 2026-09-22
- ステータス: **企画ドラフト。レビュー後にシナリオ執筆へ**
- 前提: 第1〜3展示室は実装済み。エンジン（ビート／サーフェス／リプレイ／図鑑）は流用する

---

## 0. なぜこの題材を追加する価値があるか

既存3室は**すべて1対1**の関係で成立している。第4展示室だけが構造的に違う。

| | 第1〜3展示室 | 第4展示室 |
|---|---|---|
| 相手 | 1人（＋その場にいない権威） | **数十〜数百人の「参加者」** |
| 疑うコスト | 相手ひとりを疑えばよい | **全員を疑うことになる** |
| 沈黙の意味 | 何も起きない | **取り残される** |
| 反論したとき | 相手が引く・言い訳する | **集団に否定される** |

つまりこの展示は「新しい詐欺をもう1つ足す」のではなく、**これまでの3室では体験できなかった心理（社会的証明・同調圧力・FOMO）を扱うために必要**という位置づけになる。第1展示室と手口の後半（偽サイト・爆益・出金停止）は重なるが、**前半の信用形成のメカニズムが根本的に違う**ため、重複感は出ないと判断する。

### 規模の裏づけ（要・公開前再確認）

警察庁の発表によると、2025年（令和7年）のSNS型投資詐欺は**認知件数 9,523件／被害額 1,288.0億円**（前年比 +47.9%）。当初の接触手段は**バナー等広告 3,785件／ダイレクトメッセージ 3,549件**で、この2つで全体の約8割を占める。つまり**この展示が扱う入口が、いま最大の入口**である。

## 1. 手口のフェーズ整理

### Phase 1｜入口：著名人なりすまし広告・DM
- SNSのタイムラインに「〇〇氏の無料投資講座」「日本株で資産を10倍に」といった広告が流れる
- クリックすると **LINE公式アカウント**の友だち追加に誘導される
- 個人からのDM（「間違えました」型を含む）から始まるパターンもある
- **実在の著名投資家・経済評論家・大手証券会社の名前と顔写真が無断で使われる**のが特徴

### Phase 2｜グループ招待：「先生の無料勉強会」
- アシスタントを名乗る女性アカウントから、**参加者100〜300人規模のグループ**に招待される
- グループ名は「【第3期】〇〇投資研究会」「本日の推奨銘柄共有部屋」など、期や回を感じさせる命名
- 入室直後、すでに大量の会話ログが流れており、**「自分は途中から参加した」という感覚**を与える

### Phase 3｜劇団の稼働：先生とサクラの役割分担
グループの参加者の大半が演者である。調査した範囲では、サクラは役割ごとに分業している。

| 役 | 発言内容 | 機能 |
|---|---|---|
| **先生（アナリスト）** | 相場分析、推奨銘柄、精神論 | 権威。基本的に個別対応しない＝希少性 |
| **アシスタント（女性）** | 事務連絡、励まし、個別フォロー | 唯一の窓口。のちに個別LINEへ引き込む |
| **知的役** | 「先生、〇〇のPERはどう見ますか」 | 先生に語らせる。議論の体裁を作る |
| **初心者役** | 「まだ怖いです」「少額でもいいですか」 | **プレイヤーの不安を先回りして代弁し、解消してみせる** |
| **ヨイショ役** | 「先生のおかげで今月+80万！」 | 利益自慢。社会的証明の本体 |
| **日常役** | 「おはようございます」「出勤なう」 | グループを生きた場に見せる |

**初心者役の存在がこの手口の要**である。プレイヤーが抱く疑問を、プレイヤーより先に、より弱い立場の誰かが口にし、それが丁寧に解消される。**自分で質問する必要がなくなり、同時に「質問しても大丈夫な場だ」という誤った安心が生まれる。**

### Phase 4｜少額投資と「爆益」の共有
- 「まずは5万円から」と偽アプリ／偽取引所への登録を促される
- 入金すると、画面上の資産が短期間で大きく増える（数字は運営が書いているだけ）
- **少額の出金は本当に通る**（第1展示室と同じ構造）
- グループには連日、他人の利益スクリーンショットが投稿され続ける

### Phase 5｜裏誘導：グループから個別LINEへ
- アシスタントから個別トークが届く
- 「グループでは言えませんが、あなたは筋がいいと先生が」「特別枠の案内です」
- **ここでUIが1対1に戻る**。集団の圧で信用を作ってから、個別で金額を詰める分業になっている
- 追加入金、信用取引、レバレッジ、そして借入の示唆へ

### Phase 6｜出金停止
- 出金申請すると、順に名目が変わって要求が続く
  - 「利益分の**税金**を先に納付してください」
  - 「出金**手数料**／保証金が必要です」
  - 「アカウントの**本人確認**が未完了です（追加入金で認証）」
  - 「短期間の大口出金は**マネーロンダリング審査**の対象です」
- 支払っても出金できない。名目だけが変わる

### Phase 7｜強制退会（キック）
- 疑い始める、要求に応じない、グループで不満を書く → **グループから強制的に退出させられる**
- アシスタントにブロックされ、先生のアカウントも消える
- **「メンバーではありません」と表示され、あれだけ賑わっていた場に二度と入れなくなる**

## 2. 突かれる「認知の穴」の分析

### 2-1. 社会的証明 — 判断の外注
人は、自分で判断できない状況では「他の人がどうしているか」を判断材料にする。これは通常はうまく機能する省エネ手段だが、**参加者の実数を確認できない場所では完全に無力化する**。

重要なのは、**プレイヤーが誰も疑っていないわけではない**という点。疑っているが、「200人が信じていて自分だけが疑っている」という構図に見えるため、**疑いを口に出すコストが跳ね上がる**。

### 2-2. 沈黙の螺旋 — 異論が消えていく仕組み
グループには実際、疑問を呈する人がいる（サクラの「初心者役」を含む）。しかし、
1. 疑問が出る → 2. 複数人が即座に否定・嘲笑する → 3. 先生が「疑うのは当然です」と寛大に振る舞う → 4. 周囲が「先生に失礼だ」と反応する → 5. **以降、誰も疑問を書かなくなる**

結果として、**疑いの声が存在しない場が作られる**。プレイヤーが入室した時点で、この工程はすでに完了している。

### 2-3. FOMO（取り残される恐怖）
1対1の詐欺では、迷っている間に失うのは「その話」だけ。グループでは、**迷っている間に他人が儲けていく様子が可視化される**。

- 「今日のシグナルで+32万でした」が流れ続ける
- 自分だけが参加していない
- 損失回避（失いたくない）ではなく、**機会損失の可視化**が効く

第1展示室の「枠が2人まで」（希少性）とは効き方が違う。**希少性は言葉で作るが、FOMOは他人の姿で作る。**

### 2-4. 責任の分散
「これだけの人が参加しているのだから、問題があれば誰かが言うはず」という推論が働く。実際には誰も検証していないが、**全員が全員の存在を検証の代わりにしている**。

### 2-5. 公開の場でのコミットメント
グループ内で「参加します！」「入金しました！」と**皆の前で宣言させる**演出がある。人は、公開した立場と一貫した行動を取ろうとするため、引き返すことが「みんなの前で前言を撤回する」行為になってしまう。

### 2-6. パラソーシャル関係の借用（著名人なりすまし）
入口の広告は、**本人が長い時間をかけて築いた信用を、無断で借りてくる**。視聴者はその著名人を一方的によく知っており、初対面ではない感覚を持っている。この非対称な親近感が、最初の警戒を一段下げる。

## 3. 演出・ゲームギミック案

### 3-1. 新サーフェス：GroupChatSurface

```
┌─────────────────────────────┐
│ ← 【第3期】黎明投資研究会  187      ⋮│ ← 参加人数が常に見えている
├─────────────────────────────┤
│ 📌 先生：本日15時、重要な発表があります  │ ← ピン留めアナウンス
├─────────────────────────────┤
│ ⬤ 田中  先生、いつもありがとうございます！│
│ ⬤ ゆき  今月+82万になりました🙇‍♀️        │
│         ［利益画面のスクショ］            │
│ ⬤ 佐藤  すごい…私も勇気出して正解でした   │
│ ⬤ 山本  まだ悩んでる方、もったいないです  │
│ ⬤ みか  初心者ですが大丈夫でしょうか…     │
│ ⬤ 先生  大丈夫です。誰でも最初は初心者です │
│ ⬤ 田中  先生のこういうところが…！        │
│                    ［3人が入力中…］      │
└─────────────────────────────┘
```

既存の `ChatSurface` との差分：
- **発言者が複数**（名前＋アイコン色＋同一人物の連投まとめ）
- **参加人数の表示**（実数は確認できないという展示物そのもの）
- **ピン留めアナウンス**
- **「3人が入力中…」**（複数同時）

### 3-2. 中核ギミック①：**会話が待ってくれない（流速）**

**これが第4展示室の主役ギミック。** 既存3室では、相手はこちらの返信を待つ。グループは待たない。

- 選択肢が表示されている**あいだも、サクラの発言が数秒おきに流れ続ける**
- 黙っていると画面がどんどん流れ、自分だけが止まっている感覚になる
- 制限時間バーのような「警告」は出さない。**ただ流れるだけ**で圧になる

技術的には、ビートに `ambient: Message[]`（選択待ちのあいだ一定間隔で流れる発言）を追加すれば、既存の runner をほぼ壊さずに実装できる（§7参照）。

### 3-3. 中核ギミック②：**疑義を呈したときの集団反応**

プレイヤーが「これ、詐欺じゃないですか？」を選ぶと、**1人ではなく一斉に**返ってくる。

```
⬤ 田中  は？ 何も知らないのに失礼では
⬤ ゆき  私は実際に出金できてますけど…
⬤ 山本  そういう人が一番損するんですよね
⬤ 佐藤  先生に謝ってください
⬤ みか  ちょっと、やめましょうよ…（初心者役が"仲裁"に入る）
⬤ 先生  いいんですよ。疑うのは当然のことです。
⬤ 田中  先生……！ こんな人にまで……
```

そして選択肢は2つだけになる。
- 「すみませんでした」と謝る → **以後、疑問を書けなくなる（沈黙の螺旋の完成）**
- グループを退出する → **正解ルート。ただし「自分が間違っていたのでは」という後味を残す**

**この場面が展示の核心**。1対1の詐欺では絶対に起こらない圧力で、体験者に「自分も黙っただろう」と思わせられれば成功。

### 3-4. 中核ギミック③：**個別トークへの裏誘導でUIが切り替わる**

グループ画面 → アシスタントとの1対1画面へ。演出上の狙いは2つ。

1. 「グループでは言えませんが、あなただけに」で**特別扱い**が発生する
2. **プレイヤーは第1・2展示室で慣れた1対1のUIに戻る**。既視感が安心として働く、という皮肉な構造をそのまま体験させる

### 3-5. 中核ギミック④：**強制退会（キック）**

終幕。第1・2展示室の「相手が消える」とは質を変える。

- 出金を求め続けると、ある朝**グループを開けなくなる**
- 画面には「このグループのメンバーではありません」
- **賑わっていた場は、まだどこかで続いているように見える**（実際は自分専用の劇場だったのだが、それは分からない）
- アシスタントも先生もブロック済み

「自分だけが追い出された」という形にすることで、**相談しにくさ＝孤立を最後に上塗りする**。

### 3-6. リプレイ限定の演出：**劇団員の名簿**

第4展示室のリプレイにだけ、専用のセクションを置く提案。

> **この部屋にいた「参加者」**
> | 表示名 | 発言回数 | 役 |
> |---|---|---|
> | 田中 | 24回 | ヨイショ役 |
> | ゆき | 19回 | 利益報告役 |
> | みか | 11回 | 初心者役（あなたの不安を先回りする係） |
> | 佐藤 | 14回 | 同調役 |
> | 先生 | 31回 | 権威 |
> | **あなた** | **7回** | — |
> 　
> 表示上の参加人数は187人。実際に発言したのは、あなたを含めて6人でした。

**数字で見せると一撃で分かる。** 体験中は流速で気づけないが、集計すると「同じ5人が回していた」ことが露呈する。これは既存のリプレイ機構（通った経路の記録）を集計するだけで実装でき、**この展示でしか作れない種明かし**になる。

| No | ID | 名称 | 分類 | なぜ既存タグで足りないか |

| 21 | `SOCIAL_PROOF` | 数の演出（社会的証明） | 判断を奪う | 既存 `FAKE_PROOF` は「偽の実績データ」。こちらは**他人の存在そのもの**を判断材料にさせる別物 |

## 5. プレイヤー設定（案）

> **51歳・女性。パート勤務。夫と二人暮らし、子どもは独立。**
> 昨年から新NISAを始めたが、正直よく分かっていない。
> 老後資金の不足がニュースで流れるたびに不安になる。
> SNSは、離れて暮らす娘の近況を見るために使っている。
> 預貯金は約620万円。

**理由**：既存3室のプレイヤーは42歳男性・48歳男性・62歳男性で、**全員が男性**。SNS型投資詐欺の被害者層は男女ともに広く、この展示で視点を変えることで「誰にでも起こる」という主張の説得力が増す。また、**「投資をまったく知らない人」ではなく「少しかじって不安な人」**のほうが、この手口の実際のターゲットに近い。

## 6. 倫理上の注意（SPEC.md §5 に追加が必要な項目）

この展示は既存3室より**リスクが一段高い**。以下を必須制約とする。

1. **著名人なりすましは、実在人物を一切使わない。**
   現実の手口の本質は「実在の著名投資家の顔写真の無断使用」だが、展示で実在人物を使うことは絶対にできない。**架空の著名投資家**（例：「投資家 南条 剛」）を立て、*「この広告には実在の著名人の写真が使われることが多い」*という事実は**解説側でテキストとして扱う**。
2. **実在の証券会社・取引所・SNSプラットフォーム名を使わない。**
   グループの舞台は「メッセージアプリ」、取引所は架空名とする。
3. **サクラの台本を、通しで使える形にしない。**
   §5-3 の原則どおり。褒めちぎりの文面は構造が分かる最小限にとどめ、役割分担の一覧（§1 Phase 3）は**見抜く側の知識**として提示する。
4. **潜入系動画の内容をそのまま再現しない。**
   「ピロの火遊び」等の実際の潜入コンテンツは、着想元として参照するにとどめ、会話やチャンネル名を引用しない。参考として挙げる場合は S-09 の出典欄に限る。
5. **集団による攻撃の描写は、人格攻撃の再生産にしない。**
   §3-3 の演出は必要だが、実際の誹謗中傷表現をそのまま書かない。**恐怖より「言いにくさ」が伝わる強度**に調整する。

## 7. 実装コストと既存エンジンへの影響

| 項目 | 内容 | 規模感 |
|---|---|---|
| `GroupChatSurface` | 新規サーフェス。発言者の識別、参加人数、ピン留め | 中 |
| `Message.speaker` | 発言者情報（名前・色・役）を Message に追加 | 小（型追加のみ） |
| **`Beat.ambient`** | **選択待ち中も流れ続ける発言。runner に配信ループを1つ足す** | **中（唯一のエンジン変更）** |
| 劇団員の名簿（リプレイ） | 経路記録を集計するだけ | 小 |
| キック演出 | system メッセージ＋画面ロックで表現可能 | 小 |
| 手口カード5枚 | 執筆のみ | 小 |
| シナリオ本編 | 25〜30ビート想定 | 大（執筆が主） |

**エンジンへの侵襲は `Beat.ambient` の1点に収まる見込み。** 既存3室の挙動には影響しない（`ambient` を持たないビートは従来どおり）。

## 8. エンディング案（4〜6種）

| 区分 | 到達条件 | 内容 |
|---|---|---|
| A | 広告／DMの段階で離脱 | グループにすら入らずに終わる。「入口が最大の関門だった」 |
| A | 疑義を呈して**退出**する | 集団に否定されても出られた。ただし後味の悪さを残す |
| B | 登録したが入金前に離脱 | 偽アプリの登録まで。ドメインと運営者の確認で止まる |
| C | 少額（数万〜数十万）で損切り | 「最初の5万円は取るためではなく通すため」 |
| D | 大口入金 → 出金停止 → 追加支払い | 名目を変えた請求が続く |
| D | 借入まで踏み込み、最後にキック | 全財産＋借金。強制退会で幕 |

## 9. 未決事項（レビューで判断いただきたい点）

1. **タイトル**：「みんな、儲かっている」／「この部屋の全員が、味方です」／他のご提案
2. **§3-2 の流速ギミックを、どこまで強くするか。** 強くするほど体験は本物に近づくが、読む速度が追いつかない人には不快になる。**選択待ちのあいだ2〜3秒に1発言**程度を初期値として提案する
3. **`PUBLIC_COMMITMENT` タグを追加するか**（§4 の任意項目）
4. **プレイヤーを女性設定にするか**（§5）。既存3室との対比を狙う案だが、ご意向を確認したい
5. **第1展示室との重複感**。後半（偽サイト・爆益・出金停止）は構造が似る。**後半を意図的に短く**し、前半のグループ演出に尺を寄せる方針でよいか
6. **画像アセット**：偽の利益スクリーンショット（複数人ぶん）、なりすまし広告のバナー。前者は**同じ画面の数字違い**で作れるため、1枚を加工して使い回す想定
