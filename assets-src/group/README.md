# 第4展示室「みんな、儲かっている」画像アセット

## 使い方

1. 生成した画像を **このフォルダ（`assets-src/group/`）** に置く
2. `npm run optimize-images` → `public/assets/group/` に webp が出力される
3. `npm run check-assets` で配置状況を確認

## この展示室で使うファイル

| 原本ファイル名 | 配信パス | 表示場所 | 出力サイズ |
|---|---|---|---|
| `ad-banner.*` | `/assets/group/ad-banner.webp` | n01（なりすまし広告のバナー） | 幅720px |

未配置でもプレースホルダーが出るため、画面は壊れません。

## ⚠️ この画像の最重要注意：実在の人物を使わない

現実のこの手口の本質は、**実在の著名投資家・経済評論家の顔写真の無断使用**です。
展示でそれを再現することは絶対にできません。

- **実在の人物に似せない。** 生成AIで作る場合も、特定の著名人を想起させる容姿にしない
- シナリオ上の人物は**架空の「投資家 南条 剛」**。実在の同名人物がいないか、念のため検索して確認する
- **実在の証券会社・メディア・SNSのロゴを入れない**
- 「実在の著名人の写真が使われることが多い」という事実は、**解説テキスト側**で扱っており、
  画像で再現する必要はない

### 仕様

| 項目 | 値 |
|---|---|
| 縦横比 | **16:9 前後**（横長）。チャットの吹き出しの中に収まる |
| 出力 | 幅720pxに自動縮小されるので、原本は 1280〜1920px 程度あれば十分 |
| 形式 | png / jpg / webp どれでも可 |

### 入れたい要素

1. **中年男性の顔写真**（バストアップ）が左右どちらかに大きく配置されている
2. **太いゴシックの見出し**が画面の半分以上を占める
3. **黄色や赤の強調帯**、「無料」「限定」などのバッジ
4. 実際の広告っぽい安っぽさ（余白が少ない、文字が詰まっている）

### 文言（シナリオと合わせる場合）

> 【無料】投資家・南条剛が教える
> 「新NISAの次にやるべきこと」
> 受講者12,000人突破

**文字が崩れても問題ありません。** むしろ読み取れないほうが安全です（そのまま実際の詐欺に
転用されにくくなる）。「無料」「投資」の雰囲気が伝われば十分です。

### プロンプト例①（オーソドックス）

```
日本語のSNS投資セミナー広告バナー。横長16:9。
右側に50代くらいの男性のバストアップ写真（スーツ、腕組み、自信のある表情）。
左側に太いゴシック体の大きな日本語見出しと、黄色い帯に「無料」のバッジ。
下部に小さく「受講者12,000人突破」の文字。
背景は濃紺からダークブルーのグラデーションに、株価チャートの線がうっすら重なっている。
いかにもSNSに流れてくる広告らしい、余白の少ない詰まったレイアウト。
実在の人物・企業ロゴ・メディア名は含めない。
```

### プロンプト例②（より生々しい・推奨）

```
スマートフォンのタイムラインに流れてくる投資広告のバナー画像。横長。
中央やや右に、笑顔の中年男性が両手を広げている切り抜き写真。
左に大きな日本語のキャッチコピー、赤い下線と黄色のマーカー風強調。
右上に「PR」の小さな表示。全体的に彩度が高く、素人っぽいデザイン。
グラフが右肩上がりに伸びるイラストが背景に入っている。
特定の実在人物に似ていない、一般的な顔立ちの人物。企業ロゴは一切なし。
```

### 必ず除外するもの（ネガティブ指定）

```
実在の著名人に似た顔、実在の企業ロゴ、実在の証券会社名、
実在のSNSやメッセージアプリのロゴ・UI、実在のメディア名、
QRコード、読み取れる電話番号やURL
```

### ⚠️ 生成後に必ず確認すること

- **「誰かに似ていないか」を、作った本人以外の目で一度確認する。**
  この1枚だけは、似てしまった場合の影響が他の画像と桁違いです
- 画面内に実在の企業名・ロゴが紛れ込んでいないか（AIは勝手に入れることがあります）
- 「南条 剛」という名前で検索し、同姓同名の実在の投資家がいないか確認する
