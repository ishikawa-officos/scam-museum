# 第3展示室「あなたの口座が危ない」画像アセット

## 使い方

1. 生成した画像を **このフォルダ（`assets-src/police/`）** に置く
2. `npm run optimize-images` を実行（`public/assets/police/` に webp が出力される）
3. `npm run check-assets` で配置状況を確認

## この展示室で使うファイル

| 原本ファイル名 | 配信パス | 表示場所 | 出力サイズ |
|---|---|---|---|
| `fake-id.*` | `/assets/police/fake-id.webp` | q07（検察官の身分証だとされる画像） | 幅720px |
| `fake-warrant.*` | `/assets/police/fake-warrant.webp` | q07（資産保全命令書だとされる書面） | 幅720px |

未配置でも画面は壊れません。ファイル名入りのプレースホルダーが表示されます。

---

## ⚠️ この2枚だけは、他の画像と扱いが違います

**この2枚は、精巧に作るほど危険になります。** 他の展示画像（人物写真・食事・督促状）と違い、
偽の身分証と偽の令状は、**そのまま実際の詐欺に転用できてしまう**種類の素材です。
この展示のために作った画像が、この展示の外で使われることは避けなければなりません。

### 満たすべき条件

- **実在の警察手帳・検察官記章・官公庁の紋章（桜章、五三桐など）を再現しない**
- **実在の官庁名を正式名称で大きく入れない。** シナリオ側でも「〇〇県警」「△△警察署」と
  伏せてあるので、画像も同じ扱いにする
- **本物と見分けがつく状態にする。** 具体的には次のいずれかを満たすこと
  - 画面の一部しか写っていない（斜めから撮った、指で半分隠れている）
  - 文字が判読できない程度にぼけている
  - 全体にモアレ・反射・手ブレがあり、書式を書き起こせない
- **写実的な「完成品の偽造書類」を作らない。** 展示に必要なのは「それらしい画像が届いた」
  という体験であって、書類そのものの精度ではありません

### 迷ったら、作らないという選択肢もあります

未配置のままでも、プレースホルダーに「検察官の身分証だとされる画像」と表示され、
メッセージ本文と解説（「画像は送る側がいくらでも作れる」）は成立します。
教育効果を大きく損なわないので、**リスクを取ってまで用意する必要はありません。**

---

## プロンプト例（上の条件を満たす方向で）

- `fake-id`
  「スマートフォンで撮影された、身分証のようなカードの写真。斜めから撮られていて反射があり、
   文字は判読できない。紋章やロゴは写っていない。背景は机の上」
- `fake-warrant`
  「机に置かれた法的な書面らしき紙を、手前から撮った写真。上半分だけが写っており、
   本文は手ブレで読み取れない。公印や官庁名は写っていない」

## 生成時の共通注意（SPEC.md §5）

- 実在の人物・企業名・ロゴ・サービス名を画面内に入れない
- 実際の詐欺で使われた画像を転用しない

## ファイル名を変えたいとき

`src/content/scenarios/police-freeze.ts` の `media.src` を書き換えてください。
