# 第2展示室「支えたい、という気持ち」画像アセット

## 使い方

1. 生成した画像を **このフォルダ（`assets-src/itadaki/`）** に置く（png / jpg / webp どれでも可）
2. プロジェクトルートで次を実行する

```bash
npm run optimize-images
```

3. `public/assets/itadaki/` に、用途に応じてリサイズされた `.webp` が出力される
4. 配置状況は `npm run check-assets` で確認できる

## この展示室で使うファイル

| 原本ファイル名 | 配信パス | 表示場所 | 出力サイズ |
|---|---|---|---|
| `yua-avatar.*` | `/assets/itadaki/yua-avatar.webp` | チャットヘッダー | 128×128 正方形 |
| `yua-rent-notice.*` | `/assets/itadaki/yua-rent-notice.webp` | i17（家賃の督促だという書面） | 幅720px |
| `yua-meal.*` | `/assets/itadaki/yua-meal.webp` | i20（1日1回の食事） | 幅720px |

未配置でも画面は壊れません。ファイル名入りのプレースホルダーが表示されます。

## この展示室に固有の注意

この2枚は、どちらも**「確かめようがないのに証拠として機能してしまう画像」**として展示に組み込まれています。
生々しさより、検証できなさが伝わることを優先してください。

- **`yua-rent-notice`**：宛名・差出人・社名が読み取れないように作ること。
  実在の管理会社名や書式を模した場合、その会社が詐欺に関与しているように見えます。
  紙面の一部だけが写り込んだ、手持ちで撮った写真程度が適切です。
- **`yua-meal`**：みじめさを強調しすぎないこと。この展示の主題は貧困の描写ではなく、
  同情がどう判断を曲げるかです。
- **`yua-avatar`**：実在の人物に似せないこと。また、未成年に見える人物は避けてください。
  設定は23歳です。

## 生成時の共通注意（SPEC.md §5）

- 実在の人物・企業名・ロゴ・サービス名を画面内に入れない
- 詐欺で実際に使われた画像を転用しない（被害者の写真が流用されている可能性があります）
- 性的な描写は扱わない（SPEC.md §5-6）

## プロンプト例（画像生成AI向け）

- `yua-avatar`
  「20代女性のプロフィール写真。カフェの窓際、自然光。特定の人物に似ていない一般的な顔立ち。
   落ち着いた服装。上半身のみ」
- `yua-rent-notice`
  「机の上に置かれた一枚の書面を、スマートフォンで斜めから撮った写真。
   文字はぼやけて読み取れない。会社名やロゴは写っていない」
- `yua-meal`
  「小さなテーブルの上に、おにぎりが一つだけ置かれている写真。部屋の照明は暗め。
   生活感のある簡素な食事」

## ファイル名を変えたいとき

`src/content/scenarios/itadaki.ts` の `media.src` / `contact.avatarSrc` を書き換えてください。
パスはすべて `/assets/itadaki/...` から始まる絶対パスです。
